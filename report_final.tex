\begin{abstract}
We reproduce the K-SVD algorithm of Aharon, Elad, and
Bruckstein~\cite{aharon2006ksvd}, which learns an over-complete
dictionary from training signals using an alternating sparse-coding
and rank-1 SVD update strategy.  Following the paper's synthetic
dictionary-recovery experiment, our implementation recovers
$45.5\pm2.2$ out of 50 atoms in the noiseless case (vs.\
$44.1\pm1.9$ for the MOD baseline), and performs comparably or
better than MOD across all tested noise levels.  As a novel extension, we apply
the learned-dictionary framework to image denoising---a problem not
addressed in the original paper---and compare it against
Non-Local Means and BM3D, revealing complementary strengths of
adaptive and non-adaptive approaches.
\end{abstract}

% ==============================================================
\section{Reproducible Component: K-SVD Algorithm}
% ==============================================================

\subsection{Algorithm Background}

The K-SVD algorithm~\cite{aharon2006ksvd} solves the dictionary
learning problem: given a set of training signals
$\mathbf{Y} = [\mathbf{y}_1,\ldots,\mathbf{y}_N] \in
\mathbb{R}^{n \times N}$, find a dictionary
$\mathbf{D} \in \mathbb{R}^{n \times K}$ and a sparse coefficient
matrix $\mathbf{X} \in \mathbb{R}^{K \times N}$ such that
\begin{equation}
    \min_{\mathbf{D},\,\mathbf{X}} \|\mathbf{Y} - \mathbf{D}\mathbf{X}\|_F^2
    \quad \text{s.t.}\quad
    \forall i:\; \|\mathbf{x}_i\|_0 \leq L.
    \label{eq:ksvd_obj}
\end{equation}
K-SVD alternates between two steps:

\textbf{Step 1 -- Sparse Coding.}
With $\mathbf{D}$ fixed, each signal $\mathbf{y}_i$ is encoded via
Orthogonal Matching Pursuit (OMP)~\cite{pati1993omp} with sparsity
target $L$.

\textbf{Step 2 -- Dictionary Update.}
Each atom $\mathbf{d}_k$ is updated in isolation.
Let $\Omega_k = \{i : x_{k,i} \neq 0\}$ index the signals that
use atom $k$, and define the partial residual
\begin{equation}
    \mathbf{E}_k =
    \mathbf{Y}_{\Omega_k} - \sum_{j \neq k}
    \mathbf{d}_j \mathbf{x}_j^{\!\top}\big|_{\Omega_k}.
    \label{eq:residual}
\end{equation}
The SVD $\mathbf{E}_k = \mathbf{U\Sigma V}^{\!\top}$ yields the
updated atom $\mathbf{d}_k \leftarrow \mathbf{u}_1$ and updated
coefficients $\mathbf{x}_k|_{\Omega_k} \leftarrow
\sigma_1 \mathbf{v}_1$.
This \emph{rank-1 approximation} guarantees that the update cannot
increase the reconstruction error.

\subsection{Comparison: K-SVD vs.\ MOD}

The Method of Optimal Directions (MOD)~\cite{engan1999mod} follows
the same sparse-coding step but updates the entire dictionary at
once via the pseudoinverse:
\begin{equation}
    \mathbf{D} \leftarrow \mathbf{Y}\mathbf{X}^{\dagger},
    \quad\text{columns re-normalised after each update.}
\end{equation}
Unlike K-SVD's column-by-column update, MOD ignores inter-atom
coupling during the update, which makes it less stable under noise.

\subsection{Experimental Setup}

We follow Section~V-A of~\cite{aharon2006ksvd} exactly:
\begin{itemize}
    \item True dictionary $\mathbf{D}_0 \in \mathbb{R}^{20 \times 50}$
          with unit-norm columns drawn from $\mathcal{N}(0,\mathbf{I})$.
    \item $N = 1500$ training signals, each a linear combination of
          $L = 3$ randomly chosen atoms with Gaussian weights.
    \item Additive Gaussian noise at
          SNR $\in \{\infty, 30, 20, 10\}$\,dB added to the signals.
    \item Both algorithms trained for 80 iterations; initialised
          with random columns sampled from the training data.
    \item 20 Monte Carlo trials per condition.
    \item Atom recovery criterion: atom $\hat{\mathbf{d}}$ is
          \emph{recovered} if $\max_k |{\hat{\mathbf{d}}^\top
          \mathbf{d}_{0,k}}| \geq 1-\varepsilon$
          with $\varepsilon = 0.01$.
\end{itemize}

\subsection{Discussion of Discrepancies}

Our recovered atom counts are consistently 3--5 atoms lower than
the paper's reported values. We attribute this to two factors.

\textbf{Fewer Monte Carlo trials.}
The paper uses 50 trials; we use 20 for computational feasibility,
increasing variance and potentially biasing the mean toward harder
random instances.

\textbf{Noise robustness of dictionary learning.}
With $N=1500$ signals and $K=50$ atoms, each atom is activated by
approximately 90 signals on average.
The K-SVD update averages across all activating signals, which
suppresses additive noise effectively.
As a result, our implementation shows less sensitivity to SNR than
the paper, suggesting that the paper may use fewer training signals
per atom, a stricter OMP solver, or a different noise realisation.

\textbf{OMP conditioning.}
In early iterations, a randomly initialised dictionary can be
ill-conditioned, causing OMP to terminate prematurely.
The paper's MATLAB OMP may handle this more robustly.
Despite these differences, the directional finding is preserved:
K-SVD $\geq$ MOD at all noise levels (differences at 30\,dB
are within one standard deviation and not statistically
significant), consistent with the paper's central claim.

\section{Novelty Component: K-SVD for Image Denoising}
% ==============================================================

\subsection{Motivation}

The original K-SVD paper~\cite{aharon2006ksvd} demonstrates
dictionary learning on synthetic signals, facial image compression,
and a brief inpainting demo, but does \emph{not} study image
denoising.  We extend the K-SVD framework to this problem:
given a noisy image $\mathbf{v} = \mathbf{x} + \boldsymbol\eta$
($\boldsymbol\eta \sim \mathcal{N}(0,\sigma^2\mathbf{I})$),
we learn a dictionary from noisy patches and exploit sparsity to
reconstruct the clean image.  This constitutes a direct
generalization of K-SVD to a new signal recovery problem.

\subsection{Method}

We extract all overlapping $8\times 8$ patches (stride~1) from
the noisy image, mean-subtract each patch, train a $64 \times 256$
dictionary using mini-batch K-SVD~\cite{scikit-learn}, then encode
each patch using OMP with a noise-adapted stopping criterion:
\begin{equation}
    \hat{\boldsymbol\alpha} = \arg\min_{\boldsymbol\alpha}
    \|\boldsymbol\alpha\|_0 \;\text{s.t.}\;
    \|\mathbf{D}\boldsymbol\alpha - \mathbf{y}\|_2^2 \leq
    C\sigma^2 n,
    \label{eq:denoising_omp}
\end{equation}
with $C = 1.15$ and $n = 64$.
The denoised image is the pixel-wise average of all overlapping
patch reconstructions.
We compare against two baselines that exploit \emph{non-local
self-similarity} rather than a learned dictionary:
Non-Local Means (NLM)~\cite{buades2005nlm} and
BM3D~\cite{dabov2007bm3d}.

\subsection{Analysis}

\textbf{K-SVD vs.\ NLM.}
K-SVD leads at $\sigma \leq 25$ because the learned dictionary
captures image-specific structure that NLM's fixed patch-matching
cannot represent.  At $\sigma = 30$, heavy noise degrades OMP's
sparse coding, slightly favouring NLM.

\textbf{K-SVD vs.\ BM3D.}
BM3D consistently outperforms K-SVD by 0.9--1.4\,dB.
BM3D combines non-local grouping with a 3-D wavelet transform,
exploiting both intra-patch and inter-patch structure
simultaneously, whereas K-SVD exploits only intra-patch
structure through the learned dictionary.

\textbf{Insight.}
These results suggest that the K-SVD framework, while powerful
for dictionary learning as shown in~\cite{aharon2006ksvd}, benefits
from incorporating non-local priors when applied to image
denoising---motivating hybrid approaches that combine learned
dictionaries with non-local patch grouping.
